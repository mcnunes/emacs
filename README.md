# Emacs Configuration

My personal, version-controlled Emacs setup for daily development and text editing workflows.

## Overview

A lightweight, reproducible Emacs configuration designed to sync custom settings, custom packages, and UI preferences across environments.

## Requirements

- **GNU Emacs** (27.1+ recommended)
- **Git**

## Quick Start

Clone into your user configuration directory:

```bash
git clone https://codeberg.org/mcnunes/emacs.git ~/.emacs.d/
```
